# ADHD Visual Novel Reader

A lightweight Windows visual-novel-style reader designed for ADHD readers. It displays documents (.txt, .md, .docx, .pdf, .epub) sentence by sentence with responsive character expressions and dynamic backgrounds.

## Features
- **Sentence-by-Sentence Display:** Typewriter-style visual novel presentation with adjustable speed.
- **Multi-Format Support:** Reads plain text, Markdown, Word (.docx), PDF, and EPUB books.
- **ADHD Stimulation Controls:** Reactive character expressions, rotating scenery, and custom ambient sounds.
- **Customization:** Drop your own backgrounds, sprites, books, fonts, and UI skins into user folders.
- **Automatic In-App Updates:** Checks and updates seamlessly within the app.

## Download & Installation
Download the latest pre-built Windows release from the [Releases](https://github.com/katalepsis69/VN/releases) page.
Unzip `VNReader-vX.X.zip` anywhere on your PC and run `VNReader.exe`.
